# fork-create_connected-compact_transmission
fork create_connected-compact_transmission. форк create connected, позволяющий создавать более компактные трансмиссии. 
Добавленые блоки:
‎
‎

Секвентальная четырёх ступенчатая коробка передач: Компактная КПП в один блок, позволяет быстро и удобно менять скорость вращения. Передачи: R, N, 1, 2, 3, 4. Имеет гуи для настройки передаточного числа каждой передачи, кроме N естественно. (текстура гуи спизжена из create) 
‎


Rotator: по сути компактная версия сцепления и реверсивной передачи, без редстоун сигнала вращение нету, при подаче сверху или снизу блока меняет направление вращения. Полезно например для компактной башни танка.

Ускоритель: работает как redstone resistor из clockwork только наоборот. При отсутствии редстоун сигнала скорость вращения не изменяется.

Ускоритель со сцеплением: тоже самое, только без редстоун сигнала блокирует вращение.

Выхлопная труба, автоматически выводит углекислый газ из двигателей tfmg при подключении. 

Топливный насос, автоматически качает топливо в двигатель (только если он работает). Максимальная длина перекачки 1 блок.
